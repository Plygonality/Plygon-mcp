# Prompts that make Plygon MCP look good

Copy these into Cursor once Blender is listening.

## Instant demo

> Look at my Blender scene, then create a studio-lit chrome Suzanne on a matte plane. Three-point lighting, camera framed, metallic 0.85 / roughness 0.12. Screenshot the viewport when you're done.

## Product still

> Build a product-shot scene: a torus on a concrete-colored plane, 35mm camera, soft key from camera-left, cool rim from the back. Export GLB to `/tmp/plygon-demo.glb`.

## Fix-my-scene

> Read the scene. Tell me what's wrong with scale, clipping, and lighting — then fix it. Don't delete my work.

## Tech-art blockout

> Turn the selected mesh into a low-poly prop: bevel the hard edges, give it vertex-friendly materials, name things cleanly, and export GLB.

## Agent loop

> Screenshot the viewport. If the silhouette is weak, move the camera and lights until it reads. Stop when the screenshot looks like a keyframe, not a default cube.
